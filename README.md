# OverBlaze desktop app

Windows and Ubuntu/Linux app for [OverBlaze](https://overblazeplay.web.app). It opens the OverBlaze website in its own window;
press **Play** to enter the game. F11 = fullscreen, F5 = reload, Alt+← = back to the start page.

Downloads: see **Releases** (built automatically by GitHub Actions when a `v*` tag is pushed).
