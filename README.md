# OverBlaze desktop app

Windows and Ubuntu/Linux app for [OverBlaze](https://overblazeplay.web.app). The game runs in the app's own window (not a browser);
press **Play** on the start screen. The website's Play button opens the app via overblaze://. F11 = fullscreen, F5 = reload, Alt+← = back to the start page.

Downloads: see **Releases** (built automatically by GitHub Actions when a `v*` tag is pushed).
